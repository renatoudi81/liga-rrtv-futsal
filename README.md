# Controle Disciplinar — 1ª Liga RRTV de Futsal

Sistema de controle disciplinar (cartões, suspensões, artilharia) da 1ª Liga RRTV de Futsal.

Arquivo único, sem dependências externas. Os dados ficam no navegador de quem acessa (localStorage). Use os botões **Backup** e **Restaurar** no rodapé para mover os dados entre dispositivos.

## Publicação

Site estático. O `index.html` é servido direto, sem build.
